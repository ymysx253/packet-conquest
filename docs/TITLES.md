# 称号の案(個人マップ)

作成: 2026-10-26(ユーザー依頼: 個人の称号をいろいろ考える。例として 100 問正解・路線制覇・地域制覇(地区・市・関東など)・幻の航路で行ける島・レベル制覇)。**ここは下書き(案)**。どれを作るか、細かい決まり(第 3 章)はこれから決める。プログラムはまだ変えない。

数字は 2026-10-26 の公開の拠点 117,222 件で数えたもの。

## 1. 考え方

- 個人マップは取られることがないので、称号は**一度取ったら記録として残る**ものにする(案)。個人戦・チーム戦の「持っている間だけ」の称号(陣取り型)は別に考える
- 個人戦・チーム戦で取って個人マップに反映された拠点も数える(案。`MAPS.md` 第 2 章)
- 称号の名前は決まった形で自動で作る(「◯◯線 制覇」「◯◯市 制覇」など)。1 つずつ手で書かない

## 3. 決めること

1. 上のどれを作るか(全部作ると数万になる。市区町村・路線・島は自動でできる)
2. 「制覇」は**全部**取ることか、**3/4 以上**(地域の支配と同じ)か。個人マップは取られないので全部でも取れる
3. 「地区」の区切り(町・字のまとまり。例: 旧町村・郵便番号のまとまり・市区町村の中の地域)
4. 段(銅・銀・金 など)を付けるか
5. 点数のおまけを付けるか(付けると 100 万点・50 万点の合計が変わる)
6. 見せる場所(名前の横に 1 つ選んで出す、一覧の画面、順位表)
7. 分野・試験の名前を称号に使うときの書き方(実在の試験名は使わない案)
