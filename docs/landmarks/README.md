## 3. 集め方

- **出どころ**: Wikidata(CC0。表示義務なし)。座標の所属(都道府県・市区町村)は「国土数値情報(行政区域データ)」(国土交通省)で判定(CC BY 4.0 互換。出典表示あり)。設計書 3.4 の地理データの標準どおり
- **ジャンル**: PLACES.md の 23 ジャンルのうち、自動で集められる 20 ジャンルを Wikidata の分類に対応させた。複合施設(企業名の判断が要る)と相互接続点は対象外
- **知名度の下限**: 言語版の数がジャンルごとの下限以上(山 8、寺社 6、大学 6、博物館・公園・橋 4 など。数が多いジャンルほど高い)
- **閉館・廃止**: 解散・廃止日や閉鎖日の記録があるものは除外
- **1 つの名所が複数のジャンルに当たるとき**: 寺社 → 城・遺跡 → 空港 → … の順で決める。寺社は必ずハック不可になる(金閣寺が「庭園」として入らない)

## 5. 決まったこと(2026-10-19)

1. テーマパーク・遊園地: 入れて**ハック不可**(線をつなげない)
2. 命名権など企業名の施設: 企業名を表示して**ハック不可**
3. 寺社: 全部入れて**ハック不可**
4. 推奨は各都道府県 **50 件**(同じジャンルは 10 件まで)
5. 基礎レベルは知名度で Lv1〜5。各都道府県の庁舎 Lv15、知名度 1 位の城 Lv10、空港 Lv8

一覧の「取り込み」列が ○(ハック可)/ ○(ハック不可)のものを `tools/import-landmarks.js` が拠点マスターに入れる。最後の列「採否(確認用)」に × を入れたものは入れず、○ を入れたものは「取り込み」が空欄でも入れる。変えたら取り込みとつながりを作り直す。

## 6. 分かっている限界

- 記念碑(3 件)と山は、分類が大きく Wikidata の問い合わせが時間切れになるため、直接の分類だけで集めた。漏れがある
- 名前は Wikidata の日本語ラベル。正式名と違うことがある(例: 「三笠」は記念艦三笠)。取り込む前に名前を確かめる
- 座標は Wikidata の代表点。広い施設では入口と離れていることがある
- 島しょ部の名所(駅が無い地域の拠点にする候補)も含まれている(例: 八丈島空港、大島空港)
