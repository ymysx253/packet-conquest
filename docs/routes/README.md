## 手で足した航路(src-internal)

公開データ(国土数値情報 S10a)に無い航路を、運航会社の公開している航路図で確かめて足したもの。一覧は `hand-routes.csv`(港は `hand-ports.csv`)、取り込みは `tools/import-hand-routes.js`。入れるのは「どの港とどの港が結ばれているか」という事実だけで、時刻表・運賃・文章は写さない。運航会社の名前は画面に出さない。
