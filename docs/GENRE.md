# 拠点のジャンル一覧

作成: 2026-10-18

拠点の整理のために、いまあるジャンルと拠点の数、ジャンルごとの決まり、地図の偏り、足すジャンルの候補をまとめる。

- ジャンルの基準(使ってよいもの・避けるもの・名前の書き方)は `PLACES.md` が正。この文書は一覧と整理のためのもの
- 拠点マスターの形は `DATA-FORMAT.md` 第 4 章。ジャンルは `genre` に入れ、読み込み時に検査する(`server/map/load.js` の `GENRES`)
- 数は拠点マスターから数えたもの。町・字を入れる前は全国 12,397 拠点、関東 7 都県の町・字を入れたあと(2026-10-18)は 28,374 拠点、全国に広げたあと(2026-10-19)は 113,981 拠点、観光地を入れたあと(同日)は公開 114,551 拠点、市区町村役場・区役所・国の機関・大学を足したあと(2026-10-26)は公開 117,222 拠点

## 3. 地図の偏り(狭く感じる理由)

拠点は鉄道の駅に集まっている。鉄道の無い町村と、駅の少ない地方は拠点がまばらになる。

下の表は**町・字を入れる前**の数。町・字を全国に入れたことで、拠点が 0 の市区町村は 325 → 12 になった。残る 12 は所属未定地 6 と北方領土の 6 村(扱わない地域)だけ。

| 市区町村の拠点の数(ハック可・公開) | 市区町村の数 |
|---|---|
| 0 | 325 |
| 1 | 225 |
| 2〜4 | 557 |
| 5 以上 | 798 |
| 合計 | 1,905 |

- 拠点が駅だけの市区町村は 656
- 拠点が 0 の市区町村が多い都道府県は、北海道 82、長野 22、熊本 12、沖縄 12、福島 11
- 拠点が 0 の地域は、地図に輪郭だけが出て、攻撃も支配も起きない

## 4. 足すジャンルの候補

**町・字は採用した**(2026-10-18 決定。丁目はまとめる、占領できる、支配の数に入る、開始地点に選べる。関東 7 都県から)。下の表は、それ以外の候補で、**どれもまだ決まっていない**。

**市区町村役場・政令指定都市の区役所・国の機関の庁舎は採用した**(2026-10-26 ユーザー決定。拠点のレベルを 1〜89(2026-10-27 から 1〜90)に付け直すときの専門の段の拠点。ジャンルは `government`。役場・区役所は国土数値情報「市町村役場等及び公的集会施設データ」P05 の 2022 年版(CC BY 4.0)の本庁だけで 1,887 件(市区町村役場 1,722・区役所 165)、国の機関は Wikidata から中央省庁・出先機関・合同庁舎の 68 件。裁判所・検察・警察・消防・自衛隊・刑務所・入管・海上保安・大使館・気象台は入れない。P34(市区町村役場データ)と P28(国・都道府県の機関)は非商用なので使わない。同日に**大学を広げた**(Wikidata の日本の大学のうち、まだ無い 458 件。短期大学・高専・省庁大学校・分校は入れない)。`tools/import-offices.js`、`tools/import-universities.js`。基礎レベルは仮(役場 15、ほかは知名度で 15〜70))。

## 5. 決めてもらうこと

1. (2026-10-19 に済)町・字は全国に広げた(101,584 件)
2. **どの候補を足すか**: 町・字で地図の空白は埋まるので、役場や道の駅は「名所」として足すかどうか
3. **市区町村役場の基礎レベル**: 都道府県の庁舎(Lv15)より低くする。案: 市役所 Lv3、町村役場 Lv2、政令市の区役所は入れない(2026-10-26: 役場・区役所を入れることは決めた。いまは仮に Lv15。レベルは 1〜89 の付け直しで決める)
4. **灯台の扱い**: ハック不可で地図に出すか、入れないか
5. **名所の枠**: いまの「各都道府県 50 件」を広げるか(広げると自然の名所・博物館などが増える)
6. **出どころの確認**: 国土数値情報などの公的データを使う場合は、取り込みの前に使用許諾(商用可か)を確かめる(`DATA-FORMAT.md` 第 2 章の出典の台帳に登録する)
