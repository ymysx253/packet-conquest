# 拠点のジャンル一覧

作成: 2026-10-18

拠点の整理のために、いまあるジャンルと拠点の数、ジャンルごとの決まり、地図の偏り、足すジャンルの候補をまとめる。

- ジャンルの基準(使ってよいもの・避けるもの・名前の書き方)は `PLACES.md` が正。この文書は一覧と整理のためのもの
- 拠点マスターの形は `DATA-FORMAT.md` 第 4 章。ジャンルは `genre` に入れ、読み込み時に検査する(`server/map/load.js` の `GENRES`)
- 数は 2026-10-18 の拠点マスターから数えたもの。町・字を入れる前は全国 12,397 拠点、関東 7 都県の町・字を入れたあとは 28,374 拠点

## 3. 地図の偏り(狭く感じる理由)

拠点は鉄道の駅に集まっている。鉄道の無い町村と、駅の少ない地方は拠点がまばらになる。

下の表は**町・字を入れる前**の数。関東 7 都県は町・字を入れたことで、拠点が 0 の市区町村が無くなった(所属未定地を除く)。全国では 325 → 287。

| 市区町村の拠点の数(ハック可・公開) | 市区町村の数 |
|---|---|
| 0 | 325 |
| 1 | 225 |
| 2〜4 | 557 |
| 5 以上 | 798 |
| 合計 | 1,905 |

- 拠点が駅だけの市区町村は 656
- 拠点が 0 の市区町村が多い都道府県は、北海道 82、長野 22、熊本 12、沖縄 12、福島 11
- 拠点が 0 の地域は、地図に輪郭だけが出て、攻撃も支配も起きない

## 5. 決めてもらうこと

1. **町・字を全国に広げる時期**: 関東の遊び心地を見てから。広げると全国で約 10 万件の見込み(関東 7 都県で 1.6 万件からの概算)
2. **どの候補を足すか**: 町・字で地図の空白は埋まるので、役場や道の駅は「名所」として足すかどうか
3. **市区町村役場の基礎レベル**: 都道府県の庁舎(Lv15)より低くする。案: 市役所 Lv3、町村役場 Lv2、政令市の区役所は入れない
4. **灯台の扱い**: ハック不可で地図に出すか、入れないか
5. **名所の枠**: いまの「各都道府県 50 件」を広げるか(広げると自然の名所・博物館などが増える)
6. **出どころの確認**: 国土数値情報などの公的データを使う場合は、取り込みの前に使用許諾(商用可か)を確かめる(`DATA-FORMAT.md` 第 2 章の出典の台帳に登録する)
