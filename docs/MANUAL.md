# パケット陣取り 遊び方(下書き)

プレイヤー向けの説明書の下書き。**いま動いている規則**を書き、まだ無いものは「予定」と付ける。規則が変わったら `DESIGN.md` と一緒にここも直す(2026-10-18 作成)。

## 1. どんなゲームか

- 日本の駅や名所が「拠点」として地図に並んでいる。ネットワークの問題に正解すると拠点を奪え、自分のネットワークが隣へ広がっていく。
- 世界は 1 つ、制限時間はない。いつ来ても、いつやめてもよい。遊んだ分は残る。
- 問題はサブネット計算から始まり、拠点が強くなるほど難しい知識が問われる(レベル 1〜999)。難しさは知識の難しさだけで決まり、早押しや制限時間はない。

## 2. はじめかた

1. 名前を入れる(12 文字まで)。
2. **登録国**を選ぶ(いまは日本だけ)。
3. **開始地点**を選ぶ。選べるのは **Lv1 の駅と町・字**だけ(東京駅や新宿駅のような大きな駅、空港、名所からは始められない。誰でも同じ条件で始めるため)。名前で検索するか、「地図から選ぶ」で地図をタップする(町・字は拡大すると出る)。選べない駅を検索すると、近くの選べる駅や町・字が出る。空欄なら丸の内(東京駅の隣の町)。同じ名前の駅が別の県にもあるので、候補の市区町村名で確かめる。候補には「ここから始めた人数」が出るので、混んでいる駅を避けられる。
4. 「参加する」を押すと、開始地点のそばに**あなた専用の拠点**が生まれ、開始地点ともう 1 つ近い拠点につながる。
5. 画面の上の帯にある「復帰コード・引っ越し」ボタンで出る**復帰コード**を控える。別の端末やブラウザで続けるときに入れると、同じプレイヤーに戻れる。他の人には教えない。

開始地点が混んでいると、少し離れた場所(最大 1 km)に生まれる。1 km まで空きが無いと「満員」になるので別の駅を選ぶ。

- **引っ越し**: 自分のパネルの「引っ越し」で地図から新しい開始地点(Lv1 の駅か町・字)を選ぶと、自分の拠点がそのそばに作り直される(1 日 1 回)。奪った拠点は残るが、**新しい拠点から線でつながるまでは「ただあるだけ」で、そこから先へは広げられない**。つなぎ直せばまた使える。

## 3. 地図の見方

| 見た目 | 意味 |
|---|---|
| 形 | 拠点のレベル(難しさ)。Lv1 は丸、Lv2 は四角、Lv3 は三角…。レベルごとに形が違う(地図の下の「凡例」ボタンで見られる。Lv999 までは「形の一覧」ページ) |
| 色 | 所有者の色。色が無いものは中立。**チームに入っている人の拠点は、印の線がチームの「枠」の色、印の中がチームの「背景」の色(塗りつぶしの形のレベルは枠の色で塗る)、拠点の名前がチームの「文字」の色** |
| 水色の面 | 海・湖 |
| 真ん中の白い点 | **あなたの**拠点 |
| 同じチームの色 | **チームの仲間の**拠点 |
| 色のにじみ | 陣地。持っている拠点のまわりが持ち主の色で薄く色づく |
| 線 | 拠点どうしの**つながり**。つながるのは**すぐ隣だけ**で、間にほかの町がある拠点とはつながらない(飛び越えない)。**海の上でもつながらない**(島へは航路か、橋やトンネルを通る路線で渡る)。町はとなりの町と、駅・名所はまわりの町と、名所は間に町の無い近くの駅とつながる |
| 白と黒の線 | **路線**(電車)。同じ路線の前後の駅とつながる。本当の線路の形に沿って描く。縮小しても(広域表示になるまで)いつも濃く出る |
| 青緑と白の線 | **新幹線** |
| 色と白の線 | **占領された路線**。両端の駅を同じ人が持つと、黒の部分がその人の色(チームならチームの枠の色)になり、少し太くなる |
| 黄色く光る輪 | いま攻撃できる拠点 |
| 色つきの弧 | 侵入の進捗。自分の色はあなた、灰色はほかの人 |
| 点線の輪 | 守られている拠点(生まれたばかり) |
| 薄い表示 | ハックできない場所(寺社、テーマパーク、命名権など企業名の施設、重要インフラ)。線もつながっていない。企業名の施設は情報パネルに企業名が出る |
| 上の小さな四角 | 強化の段数 |

拠点をタップすると情報が出る(名前の読み、難易度、点数、所有者、突破に必要な回数、路線)。読みは分かる拠点だけ。選んだ拠点からは、つながっている拠点まで**黒い線**が出る(縮小していても全部出る。縮小で隠れている町・字は黒い点)。地図の何も無いところを押すと選択が外れ、線は元の色に戻り、出ていた問題文も消える。拡大は 150 倍まで。縮小すると区・市の名前が並び、支配している人がいればその色の帯で出る。

- **自分とチームの拠点は、縮小してもいつも出て、薄くならない**(レベルが低い拠点も出る)。
- 地図の左上のボタンで、持ち主の色をどこまで出すかを切り替えられる。「**自分だけ**」はあなたの拠点だけ、「**チームまで**」はチームの仲間の拠点も、「**全員**」はほかの人の拠点も色で出す。出さない持ち主の拠点は中立と同じ灰色になる(持ち主は情報パネルで見られる)。選んだものはその端末が覚えている。

## 4. 攻撃(拠点を奪う)

- **攻撃できるのは、自分の拠点から所有拠点を線でたどって届く拠点の隣だけ。** 隣から順に広げていく。線が切れた所有拠点(薄く表示)からは広げられない。
- 攻撃するとその拠点のレベルの問題が**ダイアログ**で出る。4 択は番号キー 1〜4 でも答えられる。レベルによっては答えを書き込む問題もある(表や長い入力がある問題はダイアログが広くなる)。
- 答えると、同じダイアログに正解・不正解と解説が出る。「**続けて解く**」で同じ拠点の次の問題へ進める(突破には何回か正解が要るため)。「閉じる」(または Esc)で問題をやめる。もう一度拠点を押せば新しい問題が出る。
- **突破に必要な正解の回数は、その拠点につながる線の本数。** 末端の駅は 1 回、乗換駅は多い(例: 東京駅 9 回、新宿駅 14 回)。回数に達すると占領。途中の進捗は拠点に残り、占領されたときに消える。
- 不正解だと 5 秒間、操作できない(お手付き)。何回続けて間違えても 5 秒。待ち時間はサーバーが覚えている。問題のダイアログにも「お手付き: あと ◯ 秒」とバーが出て、終わるまで「続けて解く」は押せないので、つなぎ直しても短くならない。
- 奪うと点が入る(その拠点の点数 + 強化の段数)。相手は同じ分を失う。
- 他人の拠点は、その人の守りが育っているほど難しい問題になる(他人の拠点は最低 Lv4)。

## 4.4.0 拠点のレベル

- 拠点のレベルは、出題される問題の難しさ。町・字は Lv1〜9、ふつうの駅は Lv10、観光地は Lv15〜300(温泉・滝・岬・峠・町並み など。世界遺産・特別名勝は Lv300、各都道府県で一番の観光地は Lv150)、乗り換え駅は Lv30 以上、主要駅は Lv200、空港は Lv150〜500、城・塔は Lv300、都道府県庁舎は Lv400、東京都庁は Lv600、国会議事堂は Lv777。
- **そのレベルの問題がまだ無い拠点は、占領できない。** 線はつながっていて選べるが、問題が出ない(情報パネルに「準備中」と出る)。問題が増えるにつれて、占領できる拠点も増える。
- 強化も、上げた先のレベルの問題があるときだけできる。

## 4.4.1 町・字

- 駅や名所のほかに、**町・字**(銀座、丸の内、奥多摩町の氷川 など)も拠点になっている。占領でき、開始地点にも選べる。
- 町・字は、境界が接している隣の町・字と、その中にある駅・名所とだけ線でつながっている。町から町へは一歩ずつしか進めない。
- 遠くへ行くには、鉄道の駅や空港・港を押さえるのが近道。
- 町・字は数が多いので、地図をかなり拡大したときだけ出る(自分の拠点・攻撃できる町は縮小していても出る)。

## 4.5 空港・港と航路

- 空港と港はレベルが高め(空港 Lv150〜500、港 Lv30〜)。
- 自分の拠点からたどれる空港・港を占領すると、そこから出ている**航路(空路・海路)の先の空港・港**を攻撃できる。遠くの都市や離島へ一気に広げられる。
- 航路は「接続」なので、行きも帰りも同じように使える(片道の区別はない)。
- **航路も突破に要る回数に数える。** 航路の多い空港(羽田空港など)ほど、奪うのも守るのも大変になる。
- **空港と港は、占領されてから 5 分間は奪えない**(情報パネルに「占領されたばかりで守られています」と出る)。占領した直後を狙った待ち伏せはできない。5 分たてば、航路の先が攻め落とされる前に奪い返しに行ける。
- 航路の線は、空港・港を占領すると地図に出る。空路は紫のゆるい弧、海路はオレンジで**海の上を通る曲線**。
  - 片方の端を持っているとき: 点線(行き先を攻撃できる)
  - 両端とも持っているとき: 太い実線
  - 空港・港を選んだとき: その航路が薄く出る(どこへつながっているかの目安)。地図を動かしてその空港・港が画面の外に出ても、選んでいる間は線も情報パネルも出したまま
  - チームの仲間の空港・港の航路は、地図の左上の切り替えが「チームまで」「全員」のときに出る
- **季節航路**(伊東・館山と大島、竹芝と館山など)は、**毎日 日本時間 12:00〜19:00(サーバーの時計で UTC 3:00〜10:00)だけ**使える。その時間の外は線が出ず、航路の先を攻撃できない。情報パネルの行き先に「季節航路」と時間が出る。
- **道でつながる島**(橋やトンネルがある島・埋め立て地)は、船ではなく、ふつうの拠点の線で向こう岸とつながっている。
- **幻の航路**: 道も航路も無い島(公開データに航路が無い島)は、島の港か、港が無ければ海岸に置いた「〇〇港(仮)」という仮の港から、いちばん近い港へ幻の航路でつながっている。**1 日に 20 分だけ**使える(時間は航路ごとに違い、毎日同じ時間)。情報パネルの行き先に時間が出る。
- 情報パネルの「航路」の行き先を押すと、地図がそこへ移動する。
- 航路は実際の路線から作っている。空路は国内定期便(2025 年の実績)、海路はフェリー・貨物船などの定期便(2016 年)。

## 5. 強化(自分の拠点を守る)

- 自分の拠点をタップすると強化の問題が出る。正解すると強化が 1 段上がり、攻める側に出る問題のレベルが 1 上がる。強化に上限はない。
- 強化の問題は「いまの出題レベル」の問題。自分の拠点を Lv30 にするには Lv30 の知識が要る。
- **強化は 24 時間ごとに 1 段ずつ下がる**(最後に強化・奪取した時刻から)。基礎のレベルより下にはならない。
- 強化しても、突破に必要な回数は変わらない(回数は線の本数で決まる)。
- 攻められている途中の進捗は消せない。守る手段は強化だけで、放置すると減衰で奪われやすくなる。

## 6. 守られるもの

- **あなた専用の拠点は、誰にも占領されない。** 失うのは奪った固定拠点だけで、全滅はない。
- 生まれたばかりの拠点は 24 時間、攻撃されない。
- 始めてから 7 日間は、拠点が 3 つ以下なら攻撃されない(初心者保護)。
- 寺社、テーマパーク、命名権など企業名の施設、重要インフラは地図にあるがハックできない。

## 6.5 休まずに続けること(休眠)

- **7 日間接続が無いと、奪った拠点も自分の拠点もすべて中立に戻り、アカウントは消える。** 週に 1 度は顔を出す。メンテナンスで止まっていた時間は数えない。
- 予定: 会員(サブスク)になると、休んでもアカウントと拠点が残る。
- 予定: 本登録(ログイン + 多要素認証)。復帰コードは「お試し」で、そのまま遊び続けられる。遊ぶうちに本登録に切り替えられ、本登録しても復帰コードは使える。
- 復帰コードが漏れたと思ったら、画面の上の帯の「復帰コード・引っ越し」から「再発行」で新しいコードにする。古いコードは使えなくなる。
- 同じ接続元からの新規参加は 1 時間に 3 回・1 日に 10 回まで。復帰コードの試行は 1 分に 5 回まで。

## 7. 点数と順位

- 「点数」は、いま持っている拠点の点数の合計(拠点の点数 + 強化の段数)。奪われると減る。
- 「累計」は、これまでに奪って得た点の合計。減らない。
- 順位は点数の順。
- 順位の表は 5 種類: 総合(現在の点数・累計点・拠点数)、今週の獲得点(日本時間の月曜 0 時で区切る)、チーム(所属者の合計点)。

## 8. 地域の支配

- 区・市は、その中の拠点(ハックできるもの)の **3/4 以上**を持つ人が「支配」する。
- 都道府県はその中の区・市の 3/4 以上を支配すると支配。国はその中の都道府県の 3/4 以上。
- 支配は称号や順位に使う。問題の難しさは変わらない。
- 縮小した地図で、区・市が支配している人の色で塗られ、地域名に支配者の名前が付く。

## 9. チーム

- 画面の上の帯の「チーム」ボタン(所属するとチーム名)で開くダイアログで、チームを**作る**(名前と人数の上限 2〜20)か、仲間から聞いた**チーム コードで参加**する。所属中は新しいチームを作れない。脱退はいつでもできる。
- 同じ拠点への正解回数をチームで合算できる(例: 14 回必要な新宿駅を 3 人で分担)。情報パネルの「突破」に「チーム n/回数」と出る。
- ただし攻撃できる条件は変わらず「**自分の拠点から線でつながっている所有拠点の隣**」。チームの陣地までは自力で進む。チームの陣地の近くを開始地点に選べば、その部分を省略できる。
- 地域の支配もチーム単位で数える。順位の表に「チーム(合計点)」がある。
- **チームにいる間に取った拠点は、チームを抜けた時点でその人のものではなくなり、チームの持ち物になる**(情報パネルの所有者に「チーム「〇〇」の持ち物」と出る)。チームに入る前に取った拠点はその人に残る。チームの持ち物は、チームの人は攻撃も強化もできず、ほかの人は奪える。チームの順位(合計点・拠点数)に数える。最後の 1 人が抜けてチームが消えると、チームの持ち物は中立に戻る。7 日間接続が無くアカウントが消えるときも、抜けたときと同じ扱い。
- チームを作った人(リーダー)は、チームの**枠の色・背景色・文字の色とアイコン**を変えられる。所属している人の拠点のマークと線、支配した区・市の塗りと名札、順位の表に使われる。リーダーが抜けると、いちばん古くからいる人に移る。

## 10. 守ってほしいこと

- 復帰コードは本人の鍵。共有しない。
- 自動で解答する道具は使わない。見つけた場合は順位から外すことがある。
- 画面の表示を書き換えても判定は変わらない(判定はすべてサーバーが行う)。
