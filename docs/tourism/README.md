# 観光地の候補

更新: 2026-10-19(`tools/collect-tourism.js` が書く)。一覧は `candidates.csv`。

## 決まったこと(2026-10-19 ユーザー決定)

- 新しいジャンル「観光地」(`tourism`)。`tools/import-tourism.js` が下の一覧の「推奨」から入れる(id は `ts-<Wikidata の番号>`)。**531 件**を入れた
- 入れる種類: 温泉・景勝地・展望・滝・岬・海岸・峠・町並み(伝建地区)。入れない種類: スキー場・キャンプ場(企業の運営)、灯台(海の安全の施設)、道の駅(知名度の低いものが多い)
- 基礎レベル: 世界遺産・日本三景・特別名勝 **Lv300**(12 件) / 各都道府県で知名度 1 位 **Lv150**(47 件) / 国の指定・百選あり **Lv30〜70**(知名度で。232 件) / ほか **Lv15〜25**(240 件)。いまの名所の決め方(知名度だけ)では 9 割が Lv15 になるので、指定・百選も物差しにした
- 入れなかったもの: 平和記念公園(慰霊の場)、神戸市立外国人墓地(墓地)、末浄水場(重要インフラ)、SHIBUYA SKY・ラクーア(企業の施設)、大学の植物園・記念館・博物館(種類の分け方の誤り)。既存の拠点から 25 m 以内の 2 件(島原温泉、真名井の滝)
- 寺の庭園・塔頭(万福寺庭園、孤篷庵 など 12 件)は寺社と同じくハック不可
- 線: 名所と同じく 5 km 以内の駅とつなぐ(本数はレベルで)。町・字の中にあれば、その町・字ともつながる

## 候補の調べ方

出どころは Wikidata(CC0)。国土数値情報の観光資源データは使用許諾が「非商用」なので使わない。

候補 **4955** 件。既存の拠点と重なるもの 247、要確認 685、推奨 543(重なりが無く、知名度 3 以上か指定・百選があり、企業運営・灯台でないもの)。
