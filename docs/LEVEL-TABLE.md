# レベル別の問題の一覧(1〜100)

作成: 2026-10-22。**この文書は `node tools/build-level-table.js` が `docs/LEVEL-LIST.md` と `server/questions/cl/level100.json` から作る。直接書き換えない**(直すなら元を直して流し直す)。

- レベルは 1〜100(2026-10-23 ユーザー決定)。1 レベルに LEVEL-LIST の項目が 3〜5 つ入り、問題は同じレベルの中で項目が入れ替わって出る
- 90〜100 は神レベル(試験の外の上級者向け)。特別な場所に置く(置く場所はあとで決める)
- 列: **項目** = LEVEL-LIST の項目番号 / **答え方** = ○×・3 択・4 択・入力・表を読む・並べ替え・構成図・設定・模擬ターミナル / **作り方** = 生(計算・模擬で生成)・表(用語の表から)・固(固定)/ **担当** = O(Opus)・O→F(Opus が作り Fable が確かめる)・F(Fable)/ **状態** = できた・まだ・仕組み待ち(構成図・設定・模擬ターミナルの仕組みが要る)・Fable(Fable に頼む)
