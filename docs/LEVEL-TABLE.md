# レベル別の問題の一覧(1〜100)

作成: 2026-10-22。**この文書は `node tools/build-level-table.js` が `docs/LEVEL-LIST.md` と `server/questions/cl/level100.json` から作る。直接書き換えない**(直すなら元を直して流し直す)。

- レベルは 1〜100(2026-10-23 ユーザー決定)。1 レベルに LEVEL-LIST の項目が話題と難しさでまとめて入り(項目の数はレベルによって違う)、問題は同じレベルの中で項目が入れ替わって出る
- 90〜100 は神レベル(試験の外の上級者向け)。特別な場所に置く(置く場所はあとで決める)
- 1 行 = 1 レベル。太字はそのレベルの話題(server/questions/cl/level100-map.json の topic)。そのレベルで出る問題の分類を ①②③ と並べる。問題は同じレベルの中で分類が入れ替わって出る。詳しい内容(例・答え方・ヒント・試験・担当)は後ろの「分類ごとの詳しい内容」
- 列: **答え方** = ○×・3 択・4 択・入力・表を読む・並べ替え・構成図・設定・模擬ターミナル / **作り方** = 生(計算・模擬で生成)・表(用語の表から)・固(固定)/ **担当** = O(Opus)・O→F(Opus が作り Fable が確かめる)・F(Fable)/ **状態** = できた・まだ・仕組み待ち(構成図・設定・模擬ターミナルの仕組みが要る)・Fable(Fable に頼む)
