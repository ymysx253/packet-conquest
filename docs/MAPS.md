# 3 つの地図(個人マップ・個人戦マップ・チーム戦マップ)

作成: 2026-10-23(ユーザー決定)。地図を 3 つに分ける。ここでは定義だけを決める。細かいルールはこのあと決める(第 3・4 章)。**プログラムはまだ変えていない**(今のゲームは 1 つの世界のまま)。

## 1. 定義

| | 個人マップ | 個人戦マップ | チーム戦マップ |
|---|---|---|---|
| ひとことで | 自分ひとりで進める、学習と制覇の記録の地図 | 一人ずつで取り合う対戦の地図 | チームで取り合う対戦の地図 |
| 地図の持ち方 | **1 人に 1 枚**(自分だけの地図) | **全員で 1 枚を共有** | **全チームで 1 枚を共有** |
| 取り合い | なし(取られる心配がない) | あり | あり |
| 突破の回数 | **どの拠点も 1 問**(手軽に進められる) | **どの拠点も 1 問**(2026-10-23 ユーザー決定) | √(つながりの本数)(今の決まり) |
| レベル上げ(強化) | なし | あり | あり |
| 参加 | だれでも | だれでも | チームに入っている人 |

- 個人戦マップとチーム戦マップは**同じ中身**(同じ全国の拠点・線・航路)で、**別々の地図**として持ち主を持つ(個人戦で取っても、チーム戦の地図の持ち主は変わらない)
- 1 人が個人戦とチーム戦の**両方に参加できる**
- 突破の回数が √(つながりの本数) なのはチーム戦マップだけ(チームで回数を合算するため)。個人戦マップは 1 問なので、囲み(隣を 2 つ以上押さえると回数が減る)は効かない
- 今の 1 つの世界(個人とチームが混ざった形)は、この 3 つに分かれる(全部別の地図)

## 2. 3 つの地図のつながり

- **個人戦・チーム戦で自分が取った拠点は、個人マップに反映される**(取った記録として残る)。そのため、先に個人戦やチーム戦に参加したほうが、個人マップが早く埋まって見える
- 個人マップで自分で取った拠点や、個人戦・チーム戦で何度も同じ拠点を取った場合は、**個人マップにその拠点を取った回数を出す**
- **点数と順位は 3 つ**(個人・個人戦・チーム戦)。どれも「制覇した数」「合計点数」「解いた数」を出す
- 個人マップには**達成レベル**があってもよい(案。中身はこれから)

## 3. 個人マップの決まり(決まった分)

- **始め方: 全員が同じ所から始める**(2026-10-23 ユーザー決定)
- **自分の拠点は日本地図の真ん中に置く**(2026-10-25 ユーザー決定)。真ん中 = 全国の公開の拠点の位置の平均(北緯 35.926 度・東経 136.783 度。岐阜県郡上市の北のはずれ、福井県大野市との境の近く)。自分の拠点は今の決まりと同じく、いちばん近い 2 つの拠点とつながる(`HOME_LINKS = 2`): **干田野(郡上市、2.6 km、レベル 3)と長滝(郡上市、2.9 km、レベル 3)**。どちらも町・字(駅から始めない。2026-10-25 ユーザー指摘: 最初は小さい所がよい)
- 前に決めた「美並苅安駅から始め、特例でレベル 1」は取りやめ(駅から始めるのはよくないため)
- **最初に取る 2 つ(干田野・長滝)は、個人マップでは特例でレベル 1 として扱う**(2026-10-25 ユーザー決定。ふつうはレベル 3。個人戦・チーム戦の地図ではふつうのレベルのまま)
- **取れる範囲: 自分の拠点とつながっている隣だけ**(今と同じ。2026-10-25 ユーザー決定)。全員が同じ所から始めるので、**どこまで広げられるかの競い合い**になる
- **空路・海路も使える**(2026-10-25 ユーザー決定)。今と同じ形: 空港・港を取ると航路の先へ広げられる
- **出題レベルは拠点のレベルそのまま**(2026-10-26 ユーザー決定。強化が無いので上がらない。干田野・長滝だけ特例で 1)
- **個人戦・チーム戦からの反映は、その拠点で 1 問でも正解した人全員**(2026-10-26 ユーザー決定)。チーム戦で回数を合算して取った拠点は、その拠点で 1 問以上正解した仲間全員の個人マップに載る
- **個人の称号は作る**(2026-10-26 ユーザー: いろいろ考える。正解の数・路線制覇・地域制覇・幻の航路で行ける島・レベル制覇 など)。案は `docs/TITLES.md`

## 4. これから決めること(細かいルール)

- 個人マップ: 達成レベルの中身、個人の称号の細部(`docs/TITLES.md` 第 3 章)、反映された拠点の点数を個人マップの合計点数に入れるか
- 個人戦マップ: 本拠地・初心者保護・囲み・航路・称号(陣取り型)・休眠など、今の決まりのどれを使うか。**開始地点は入門(レベル 1〜15)の拠点だけ**(2026-10-26 決定。チーム戦マップも同じ)
- チーム戦マップ: 今の決まり(チームの合算・支配・チームの持ち物・人数の段など)をそのまま使うか。チームに入っていない人の扱い
- 共通: 学習のまとめ(3 つの地図の解いた数をまとめるか)、アイテム(どの地図で使えるか)、課金・アカウントの種類との関係、データの持ち方(地図ごとの持ち主)
