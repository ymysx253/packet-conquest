# 3 つの地図(個人マップ・個人戦マップ・チーム戦マップ)

作成: 2026-10-23(ユーザー決定)。地図を 3 つに分ける。ここでは定義だけを決める。細かいルールはこのあと決める(第 3 章)。**プログラムはまだ変えていない**(今のゲームは 1 つの世界のまま)。

## 1. 定義

| | 個人マップ | 個人戦マップ | チーム戦マップ |
|---|---|---|---|
| ひとことで | 自分ひとりで進める、学習と制覇の記録の地図 | 一人ずつで取り合う対戦の地図 | チームで取り合う対戦の地図 |
| 地図の持ち方 | **1 人に 1 枚**(自分だけの地図) | **全員で 1 枚を共有** | **全チームで 1 枚を共有** |
| 取り合い | なし(取られる心配がない) | あり | あり |
| 突破の回数 | **どの拠点も 1 問**(手軽に進められる) | √(つながりの本数)(今の決まり) | √(つながりの本数)(今の決まり) |
| レベル上げ(強化) | なし | あり | あり |
| 参加 | だれでも | だれでも | チームに入っている人 |

- 個人戦マップとチーム戦マップは**同じ中身**(同じ全国の拠点・線・航路)で、**別々の地図**として持ち主を持つ(個人戦で取っても、チーム戦の地図の持ち主は変わらない)
- 1 人が個人戦とチーム戦の**両方に参加できる**
- 今の 1 つの世界(個人とチームが混ざった形)は、この 3 つに分かれる(全部別の地図)

## 2. 3 つの地図のつながり

- **個人戦・チーム戦で自分が取った拠点は、個人マップに反映される**(取った記録として残る)。そのため、先に個人戦やチーム戦に参加したほうが、個人マップが早く埋まって見える
- 個人マップで自分で取った拠点や、個人戦・チーム戦で何度も同じ拠点を取った場合は、**個人マップにその拠点を取った回数を出す**
- **点数と順位は 3 つ**(個人・個人戦・チーム戦)。どれも「制覇した数」「合計点数」「解いた数」を出す
- 個人マップには**達成レベル**があってもよい(案。中身はこれから)

## 3. これから決めること(細かいルール)

- 個人マップ: 始め方(開始地点・本拠地の有無)、線の決まり(隣だけ取れるか、どこからでも取れるか)、出題レベル、達成レベルの中身、個人の称号(乗りつぶし型)、反映のしかた(チーム戦でチームの合算で取った拠点を、だれの分にするか)
- 個人戦マップ: 本拠地・初心者保護・囲み・航路・称号(陣取り型)・休眠など、今の決まりのどれを使うか
- チーム戦マップ: 今の決まり(チームの合算・支配・チームの持ち物・人数の段など)をそのまま使うか。チームに入っていない人の扱い
- 共通: 学習のまとめ(3 つの地図の解いた数をまとめるか)、アイテム(どの地図で使えるか)、課金・アカウントの種類との関係、データの持ち方(地図ごとの持ち主)
