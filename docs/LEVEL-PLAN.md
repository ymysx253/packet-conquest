# レベル整理のたたき台

作成: 2026-10-19。**同日、第 3 章の案でレベルを設定した**(ユーザー決定)。決め方は `tools/levels.js`、今あったデータは `tools/migrate-levels-v2.js` で一度だけ移した

拠点は 11 万件を超えたが、基礎レベルはほとんどが Lv1〜5 に集まっている。レベル(1〜999)の幅を拠点の重みに合わせて使い直すための材料。基準は「国 = Lv777」(2026-10-19 ユーザー提示)。

---

## 1. 前提(いまの決まり)

- **拠点のレベル = 出題の難しさ**。出題レベル = 基礎レベル + 強化の段数(`LEVELS.md` 第 3 章)。Lv700 の拠点なら Lv700 の問題(700〜799「解析と診断」)を出す
- レベルは 100 ごとに知識の領域が決まっている(`LEVELS.md` 第 2 章)

| レベル | 領域 |
|---|---|
| 1〜99 | アドレッシングと基礎 |
| 100〜199 | L2・L3 の動作 |
| 200〜299 | サービスのしくみ |
| 300〜399 | セキュリティの基礎と設定 |
| 400〜499 | ルーティングと機器設定 |
| 500〜599 | 複数拠点の設計 |
| 600〜699 | クラウド |
| 700〜799 | 解析と診断 |
| 800〜899 | 複合(攻略と防御) |
| 900〜999 | 伝説(総合) |

- **問題を作れるのは、いまは Lv1〜30 と Lv51〜60 だけ**。ほかのレベルは Lv10 までの問題で代わりに出している(仮の問題の印つき)
- 突破に要る正解の回数は、レベルではなく線の本数で決まる(DESIGN.md 第 14 章)。レベルを変えても回数は変わらない
- 強化の段数は 1 日ごとに 1 下がる
- 「国 777」は 2026-10-17 に一度決め、2026-10-18 に「地域は拠点ではなく配下の集まり」と決めたときに廃止した数字(都道府県 100〜299、地方 400〜599、大陸 888、天体 950、宇宙 999 も同時に廃止)。国そのものは拠点ではないので、今回は **拠点のレベルを割り付けるときの物差し**として使う案にしている(第 4 章 #1)

## 3. たたき台(国 = 777 を一番上の物差しにした割り付け)

国の象徴を 777 に置き、そこから下へ段を割り付ける案。出題の領域(第 1 章)とも意味が合うようにした。

| 段 | 件数 | いま | 案 | 出題の領域(案のとき) |
|---|---|---|---|---|
| 国の象徴(国会議事堂) | 1 | 30 | **777** | 解析と診断 |
| 首都の象徴(東京都庁) | 1 | 15 | 600 | クラウド |
| 国際線の拠点の空港 | 7 | 10 | 500 | 複数拠点の設計 |
| 都道府県庁舎(47 にそろえる) | 7 → 47 | 15 | 400 | ルーティングと機器設定 |
| 各県で一番の城・塔 | 47 | 10 | 300 | セキュリティの基礎と設定 |
| 各県で一番の空港 | 28 | 8 | 250 | サービスのしくみ |
| 主要駅(東京駅・新宿駅 など) | 23 | 4〜5 | 200 | サービスのしくみ |
| ほかの空港 | 53 | 5 | 150 | L2・L3 の動作 |
| 乗り換え駅・港・有名な名所 | 1,430 | 2〜5 | 30〜99(乗り入れ路線・知名度で) | アドレッシングと基礎 |
| ふつうの駅・ほかの名所 | 10,791 | 1〜2 | 10〜29 | アドレッシングと基礎 |
| 町・字 | 101,598 | 1 | **1〜9**(人口などで) | アドレッシングと基礎 |

この案だと:

- 始めたばかりの人は町・字(Lv1〜9)から始め、駅(Lv10〜)に進む。開始地点の「Lv1 の駅と町・字」の決まりは「Lv1〜9 の町・字」などに直す必要がある
- 大きな拠点ほど、強化しなくても最初から難しい問題になる。強化は「その上に積む」もの
- **Lv100 以上の問題はまだ作れない**。割り付けを先に入れると、当面は Lv10 までの問題で代わりに出る(仮の印つき)。問題の生成器ができた順に本物の問題に替わる

## 4. 設定した内容(2026-10-19)

- 第 3 章の案のとおり。町・字は人口で Lv1〜9、乗り換え駅は路線の数で 30〜99、名所は知名度で 15〜70、港は 30〜70
- 都道府県庁舎: 47 にそろえる方針で 39 道府県 + 東京都庁を入れた。岐阜・静岡・島根・奈良・愛媛・高知・山形の 7 県は、Wikidata に座標が無く、国土数値情報の「国・都道府県の機関」は非商用なので未登録
- **問題の無いレベルの拠点は占領できない**(ユーザー決定)。線はつながっていて選べるが、問題が出ない。強化も、上げた先のレベルに問題があるときだけ(問題の無いレベルまで上げて誰にも攻められなくするのを防ぐ)。いま問題があるのは Lv1〜30 と Lv51〜60
- 開始地点: 「Lv1 の駅と町・字」を「町・字(Lv1〜9)と、ふつうの駅(Lv10)」に言い換えた(指す範囲は同じ)
- 縮小表示の段ごとの下限: 段 1 は Lv30、段 2 は Lv100、段 3 は Lv250、段 4 は Lv400
- 777 は「国の象徴の拠点(国会議事堂)」に使った(第 4 章 #1 の (a))
- 観光地(同日追加): 世界遺産・日本三景・特別名勝 300、各都道府県で一番 150、指定・百選あり 30〜70、ほか 15〜25(`docs/tourism/README.md`)

## 5. 残っていること

1. 座標の無い 7 県の庁舎(ユーザーが座標を決めるか、別の出どころを探す)
2. Lv31〜50・61〜99・100 以上の問題を作る(作った順に、その拠点が占領できるようになる)

## 6. 決めてもらったこと(記録)

1. **777 の意味**: (a) 国の象徴の拠点(国会議事堂)を 777 にする(第 3 章の案)、(b) 国そのもの(地域)の難しさの目安として表示や称号にだけ使う、(c) ほか
2. **段の数字**: 第 3 章の「案」の列を直す
3. **町・字のレベル**: すべて Lv1 のままか、人口・面積・つながりの本数などで Lv1〜9 に分けるか
4. **開始地点の決まり**: 「Lv1 の駅と町・字」を、新しいレベルに合わせてどう直すか(例: Lv9 以下の町・字と Lv10 の駅)
5. **都道府県庁舎**: 47 都道府県すべてを拠点にするか
6. **入れる時期**: すぐ割り付ける(問題は当面仮のもの)か、問題の生成器が追いつくのを待つか
