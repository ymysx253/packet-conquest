# 拠点に使う名所のジャンル(世界共通)

作成: 2026-10-17

拠点の名前は **「地名」ではなく「正しい名所の名前」** を使う。地名(銀座、赤坂、下北沢 など)は範囲があいまいで、位置も難易度の根拠も決められない。名所(駅、公園、塔、寺社、競技場 など)は 1 点に決まり、世界中で同じ基準で選べる。

この文書は、使ってよいジャンル・避けるジャンル・名前の書き方を決める。拠点マスター(`server/map/data/*.json`)の名前はこの基準に従い、検証テストで `genre` を必須にする。

---

## 1. 原則

**粒度は駅ぐらい**(`DESIGN.md` 8.16)。丁目や小さな店までは最初から入れない。細かい場所は、所有者が申し込むスポンサー拠点や、ユーザーの登録(8.7)で後から増える。

1. **固有名詞の施設・場所であること**: 「〇〇駅」「〇〇公園」「〇〇寺」のように、その名前で地図に載る 1 点。町名・丁目・エリアの通称は使わない
2. **公共性があり、観光・生活で誰もが訪れる場所であること**: 私有地の住宅、個人の店は使わない
3. **攻撃対象として不適切なものは使わない**(`DESIGN.md` 3.5): 重要インフラ、医療、警察・軍、宗教の中心施設の一部、企業の本社・ブランド店
4. **ゲーム内の役割(kind)と名所のジャンル(genre)は別**: 役割(相互接続点、DC、玄関口 など)は名所に後から割り当てる。架空の「〇〇DC」のような名前は作らない
5. **その国での正式名称(現地語)を name に、英語名を nameEn に**。日本語 UI では日本語名を表示する(海外の名所はカタカナ表記を併記)

## 3. 避けるジャンル

| 避けるもの | 理由 |
|---|---|
| 町名・丁目・エリアの通称(銀座、赤坂、下北沢、お台場、谷中 …) | 1 点に決まらない。位置と難易度の根拠が置けない |
| 企業の本社・支社、ブランド店、百貨店、ホテル、オフィスビル | 実在企業を攻撃対象にする表現になる(3.5)。複合施設は名称が地名化したものだけ例外。**権利者本人が申し込んだスポンサー拠点は別**(`DESIGN.md` 8.16。審査のうえ、広告表示つきで出せる) |
| 病院・診療所 | 医療は攻撃対象にしない |
| 警察・消防・軍・自衛隊・刑務所・大使館 | 治安・防衛の施設は扱わない |
| 発電所・変電所・浄水場・ダム・通信事業者の局舎 | 重要インフラ。**地図上に存在させてもよいがハック不可**(`hackable: false`)。有料でも不可 |
| 学校(小中高)、保育園、福祉施設 | 子どもや要配慮者の施設 |
| 個人宅、住宅地、墓地(観光地化した霊園を除く) | 私的な場所 |
| 皇居・宮殿・王宮の居住区画 | 国家の象徴の中でも居住に関わる部分は避ける(庭園など公開部分は `park` として可) |
| 寺社・教会・モスク | **地図上に存在させるがハック不可**(`hackable: false`。線をつながず攻撃できない)。観光名所として表示だけする |
| 災害・事件の慰霊の場 | 遊びの対象にしない |

## 4. 名前の書き方

- 正式名称を使う。**名称を微妙に変えた表記は許さない**(正式名で出せないものは出さない)。通称が広く知られている場合は正式名称を name、通称を alias に入れる(例: name「上野恩賜公園」alias「上野公園」)
- 駅は「〇〇駅」、空港は「〇〇空港」、寺は「〇〇寺」、神社は「〇〇神宮/神社」と、ジャンルがわかる語尾を付ける
- 橋・交差点など構造物は、地名と混同しないよう「日本橋(橋)」のように補う
- 海外は現地語の正式名称を name、英語を nameEn、日本語表記を nameJa に持つ(日本の名所は name が日本語で nameJa は省略)

## 5. 拠点マスターへの反映

- 拠点の項目に `genre`(第2章の値)を必須で追加し、`alias`(任意)を持てるようにする。検証テストで genre が一覧にあること、名前に「丁目」を含まないこと、架空名の DC / IX が無いことを確認する(済 2026-10-17)
- いまの東京マスター(132 拠点)のうち、地名・エリア名を名前にしているものは、同じ場所にある名所の名前に置き換える(次節の一覧)。置き換え先がない地名は削除する
- 架空名の「〇〇DC」(神田DC、芝公園DC、豊洲DC、世田谷DC、板橋DC、多摩DC)と「大手町IX」は、実在の名所に DC / IX の役割を割り当てる形に変える(例: 「日本科学未来館」を DC 役)

## 付記: 全国の名所の取り込み(2026-10-19 決定)

- テーマパーク・遊園地は入れるが**ハック不可**(線をつなげない)。運営が企業ならスポンサー候補
- 命名権など**企業名を含む施設**は、企業名を表示して**ハック不可**(PLACES 第 3 章の「企業名そのものは不可」は、攻撃対象にしないことで満たす)
- 寺社は全部入れて**ハック不可**(第 3 章どおり)
- 各都道府県 50 件(ハック可)。一覧と基準は `docs/landmarks/README.md`

## 付記: 離島と扱わない地域(2026-10-19)

- 駅の無い離島は、空港・港、無ければ島そのものを「玄関口」として入れる(`DESIGN.md` 3.4)
- 北方領土と尖閣諸島は扱わない(領有をめぐる争いがある地域・実際に行けない地域)。立ち入り制限の島(硫黄島・南鳥島・沖ノ鳥島・南硫黄島)と基地の建設地(馬毛島)も扱わない
- 国土数値情報のうち港湾(C02)・漁港(C09)・旅客航路(N09)は使用許諾が「非商用」なので使わない。使う前に各データの使用許諾を確かめる(商用可または CC BY 4.0 のものだけ)

## 付記: 名所と境界の出どころの標準(2026-10-18 決定)

- 日本: 国土数値情報(駅は鉄道データ N02、境界は行政区域データ N03)
- 海外の駅・名所: Wikidata(CC0)。座標と名称、多言語名を使う。ジャンルは本書の 23 種に写像する
- 海外の境界: geoBoundaries(CC BY 4.0)。世界地図の縮尺は Natural Earth
- 使わないもの: OpenStreetMap(ODbL の公開義務)、GADM(非商用のみ)
- 出典は出どころごとに README と画面のクレジットへ
