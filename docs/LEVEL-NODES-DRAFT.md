# 拠点のレベルの付け直し(1〜90)の下書き

`node tools/level100-nodes.js <GML のフォルダ>` が作る(2026-10-26 ユーザー決定に沿った計算の下書き。拠点マスター・DB・ゲームはまだ変えていない)。
id → 新しいレベル の一覧は `docs/level100-nodes-draft.json`。何度流しても同じ結果になる。

## 1. 計算のしかた

- 対象: 公開の全拠点 117,222 件(占領できない名所 708 件も含む。非公開は付けない)
- 種類と並べる数:
  - 町・字: 人口(国勢調査 2020 の小地域。`tools/import-towns.js` と同じまとめ方で拠点 id ごとに足した)
  - 駅: 乗り入れる路線の数(主要駅 4〜5 はいちばん上、地域の主要な乗り換え駅 3 は 5 路線と同じ。`tools/levels.js` の TERMINALS_BY_PREF)→ 同じなら、駅とつながっている町・字(駅のある町を含む)の人口の合計
  - 名所・観光地: 知名度(Wikidata の言語版の数。`docs/landmarks/*.csv` と `docs/tourism/candidates.csv`)。同じなら 指定の有無 → 前の格(各県で一番の城・観光地など)→ つながりの本数。指定のある観光地は、世界遺産・日本三景・特別名勝を知名度 40 以上、ほかの指定・百選を 15 以上と同じに扱う(`tools/levels.js` の観光地の決まりと同じ物差し)。知名度の無いもの 122 件(東京の手作りの名所など)は前の格から目安の知名度を出した。市役所 0 件(genre government で格 15)はここに入れた
  - 空港・港: 空港は 1 年間の旅客数、港は 1 年間の便数(航路の記録の metrics の合計)。記録の無いものは記録のあるものの下に、つながりの本数で並べる。空港と港は別々に並べ、上からの割合で 1 つにまぜた
  - 庁舎・国際線の拠点の空港・国会: 決め打ちで専門(国会 → 都庁 → 国際線の拠点の空港 7 つ(旅客数の順)→ 都道府県庁舎)。国会議事堂は 90
- 入れてよい段: 町・字 入門〜上級 / 駅 入門〜専門 / 名所・観光地 初級〜専門 / 空港・港 中級〜専門 / 庁舎ほか 専門
- 境目: 種類 × 段 の件数の表を、目標の割合(入れない段は 0)から出発して、種類ごとの件数と段ごとの目標の件数に交互に合わせて決めた(反復比例調整)。その件数を、種類の中で大きい順に上から配る。同じ数のまとまり(同じ人口の町など)が境目をまたぐときは、まとまりの真ん中がある段に全部入れる
- 段の中のレベル: 種類ごとに、その段に入った拠点を順位で均等に割り振る(同じ数のまとまりは同じレベル)

## 9. 気になる点

- **専門(5%、5,862 件)は町・字を入れられないので、町・字以外 15,624 件の 37.52% が専門になる**。駅の 19.03%、名所・観光地の 27.27%、空港・港の 70.79% が専門。駅の専門のいちばん下は「1 路線・まわりの人口 16,658」で、1 路線のふつうの駅も多く専門に入る(849 件)。専門の割合を下げるか、町・字の大きい町を専門に入れてよいことにするか、決めてもらう材料
- 港には仮の港(pp-、179 件)と便数の記録の無い港が多く、空港・港は中級より下に置けないので、記録の無い港も中級以上になる(港の中級 0 件のうち記録なし 0 件)
- 港は 1 年間の便数で並べるので、短い渡し船の多い港が上に来る(いちばん上は 向島港(尾道市)94,432 便/年)。航路の記録の無い大きな港は下になる(大さん橋(横浜市中区)は 便数の記録なし・つながり 1 でレベル 61)
- 同じ数のまとまりが段の境目をまたいだもの 8 組(真ん中のある段に全部入れた)。大きいもの: 町・字「人口 240」90 件(初級〜入門 → 入門)、名所・観光地「知名度 7・前の格 15・つながり 2」44 件(上級〜中級 → 中級)、名所・観光地「知名度 4・前の格 15・つながり 4」37 件(中級〜初級 → 初級)、町・字「人口 932」24 件(中級〜初級 → 初級)、名所・観光地「知名度 9・前の格 25・つながり 3」15 件(専門〜上級 → 上級)、空港・港「1,456 便/年」13 件(専門〜上級 → 専門)。このため段の件数が目標から少しずれる
- 人口 0 の町・字 2,452 件は全部同じまとまりで入門の下の方(レベル 1)
- 町・字は上級まで入るので、人口 3,062 人以上の町(10,459 件)は上級(61〜78)。いまの開始地点の決まり(町・字はどれでも開始地点)のままだと、上級の町から始められる
- 名所の知名度は言語版の数なので、同じ数の名所が多い(知名度 3 が 624 件)。知名度と指定が同じなら前の格 → つながりの本数で並べた(名所のつながりの本数は前の格から決まる部分がある。tools/levels.js の landmarkLinkCount)。それでも同じものは同じレベルなので、段の中のレベルが飛び飛びになるところがある
- 段の中のレベルは種類ごとに均等に割るので、同じレベルでも種類によって大きさの物差しが違う(例: 専門の 90 には国会・都庁・国際線の空港と、駅・名所・空港・港の各上位が並ぶ)
